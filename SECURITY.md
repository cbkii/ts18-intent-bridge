# Security and safety

This module changes behaviour inside scoped Android processes. Keep the scope narrow.

Do not use this module to bypass third-party app licensing, paid app restrictions, banking checks, DRM, or security controls. Its purpose is TS18 stock launcher compatibility on an authorised head unit.

Report all boot instability, radio regressions, Bluetooth regressions, reverse-camera regressions, and launcher crashes as release blockers.
